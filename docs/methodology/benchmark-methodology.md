# Benchmark 方法

正式基准必须先冻结模型 revision、权重精度、KV Cache dtype、GPU 可见性、并行策略、最大上下文、显存比例、随机种子、负载长度、并发定义和重复次数。

每轮至少保存：benchmark JSON、服务日志、GPU 采样、vLLM metrics 前后快照、配置、环境和退出状态。汇总器应检查字段完整性、请求成功数、缺失值、counter 增量和重复数量。

报告需同时呈现吞吐、TTFT、TPOT、E2E、GPU 利用率、显存/KV Cache 和错误率。平均值不能替代 p50/p95/p99；多轮分位数的聚合方式必须明写。发现首轮异常时保留该轮，另做位置效应审计，不得事后删除数据以美化结论。

当前正式示例是 3 类负载、TP1/TP2、每组 3 次、共 18 轮。它建立了正常压力基线，但不覆盖 KV Cache 饱和、NCCL kernel 时间、功耗成本或真实生产流量。
