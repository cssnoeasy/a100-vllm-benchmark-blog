# 复现与安全

## 复现前检查

确认 Linux、NVIDIA 驱动、CUDA/PyTorch、vLLM、模型 revision、GPU 拓扑和服务端口，并为本次运行生成独立 `run_id`。模型权重通过受控的本地路径提供，配置中的 `${MODEL_PATH}` 和 `${ENGINE_DIR}` 不能提交真实路径。

## 凭据与网络

API key 只从进程环境变量或受控密钥系统读取，不能写入 YAML、JSON、日志、截图或结果 manifest。服务默认绑定 loopback；远程访问使用组织批准的安全通道，仓库不记录主机名、用户名、IP、远程访问命令或隧道参数。

## 结果清理

提交前检查 `.env`、密钥文件、模型权重、请求 JSONL、个人路径、内网地址和大体积文件。公开结果只保留必要统计量、脱敏后的场景和可审查的 manifest。原始请求内容若含业务数据，应留在受控存储中。

## 运行边界

故障注入、进程退出和高并发压测只能在确认无其他业务流量的环境执行。报告中必须写清是离线回放、Smoke、容量探针还是正式基准，不得把工具能运行等同于服务达到生产 SLO。
